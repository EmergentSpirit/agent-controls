# EXAMPLE probe file for the sentinel -- site-specific checks, OFF by default.
#
# Point the sentinel at your own copy:
#   sentinel.py --probes ~/my-probes.txt
#   HARNESS_SENTINEL_PROBES=~/my-probes.txt
#
# One command per line. Exit 0 is OK, anything else is FAIL, and a command that
# runs longer than 10 s is FAIL too. Lines starting with # are ignored.
#
# A PROBE LINE IS AN ARGV, NOT A SHELL LINE. It is split with shlex and run
# with shell=False, so there is no variable, no glob, no `~`, no redirection
# and no `;`. A line carrying any shell metacharacter is reported as SKIP with
# its reason -- and so is a line the parser cannot read, a binary outside the
# allowlist, and a binary used to act rather than to look. Nothing is ever
# silently dropped, and nothing is ever silently run either. The sentinel runs
# unattended from a timer: a config file must not become an execution surface.
#
# What may run: the binaries in HARNESS_SENTINEL_PROBE_ALLOW (default: test,
# curl, systemctl), resolved through PATH -- a planted /tmp/test does not pass.
#
# Each of those binaries then has an ALLOWLIST of options, not a list of
# forbidden ones. What a health probe needs is allowed; everything else is
# refused, whatever it is called:
#
#   curl       -s --silent, -S --show-error, -f --fail, -I --head,
#              -o/--output with the value /dev/null and nothing else,
#              -w/--write-out, -m/--max-time <seconds>,
#              --connect-timeout <seconds>, and exactly ONE http(s) URL
#   systemctl  the read-only verbs (is-active, is-enabled, is-failed, status,
#              show, list-units, list-timers) and the value-less flags
#              --user --system --quiet -q --no-pager --all --full --plain
#   test       one operator among -e -f -d -r -w -x -s -h -L -p -S -b -c,
#              and one ABSOLUTE path
#
# The FORM counts as much as the name: a value glued to its flag (-o/tmp/loot),
# joined with "=" (--output=/tmp/loot) or hidden in a cluster (-fsSo /tmp/loot)
# is refused. Clustering is fine for the value-less letters, so -fsS still
# works. If a check genuinely needs more, put it in a script of your own and
# add that script's name to the allowlist: a deliberate, reviewable decision
# instead of a line slipped into a config file.
#
# Nothing below ships armed. Every line is an EXAMPLE of the SHAPE of a probe,
# with a PLACEHOLDER absolute path to replace with your own. A probe that does
# not come from a real incident is noise in tomorrow's report, and noise is how
# a real FAIL gets scrolled past.

# The state directory the whole harness writes into still exists.
# No variable here on purpose: write the path out.
test -d /home/REPLACE-ME/.harness

# A service the agent depends on is running.
systemctl --user is-active --quiet example-service.service

# An internal endpoint answers.
curl -fsS --max-time 5 -o /dev/null http://127.0.0.1:8080/health

# Not allowlisted by default: reported as SKIP, with the reason, every run.
# python3 /path/to/your/own/deep-check.py

# Refused by design. Each one is reported with the reason it was refused:
#   test -d /tmp; echo pwned > /tmp/x          shell metacharacter
#   test -d "$HOME/.harness"                   shell metacharacter
#   systemctl --user restart example.service   verb is not read-only
#   curl -fsS -o /tmp/loot http://host/x       -o outside /dev/null
#   curl -fsS -o/tmp/loot http://host/x        value glued to the flag
#   curl -fsS --output=/tmp/loot http://host/x value joined with "="
#   curl -fsSo /tmp/loot http://host/x         -o hidden in a cluster
#   curl -sS --data-ascii @/etc/hostname URL   uploads a local file
#   curl -sS -D /tmp/headers URL               writes a file (and so do
#                                              --trace-ascii, --stderr,
#                                              --cookie-jar, --etag-save,
#                                              --remote-name-all, ...)
#   curl -sS -o /dev/null file:///etc/hostname URL scheme is not http(s)
